# 3D Product Studio Portfolio (Client Showcase)

A bold, modern brutalist editorial portfolio showcasing 3D product visualization, motion ads, and multi-SKU asset automation for consumer drinkware and premium packaging brands.

## Deploying on Vercel for Free

### Option 1: Drag-and-Drop (Instant in 60 seconds)
1. Go to [https://vercel.com](https://vercel.com) and log in (free account).
2. Click **Add New...** -> **Project**.
3. Drag and drop this folder (`D:\IZY_Client_Portfolio`) directly into the upload area.
4. Click **Deploy**. In under 60 seconds, you get a custom live link (e.g. `https://your-portfolio.vercel.app`) to share with clients!

### Option 2: Via GitHub / CLI
1. Initialize git in this directory (`git init && git add . && git commit -m "Initial portfolio commit"`).
2. Push to GitHub and link to Vercel, or run `vercel` in terminal.
